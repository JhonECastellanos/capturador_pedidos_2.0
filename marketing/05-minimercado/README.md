## Dolores propuestos para validar

### P05-D01 · Presentaciones de empaque confundidas

- causa: Se usa el mismo nombre corto
- consecuencia: La línea corresponde a otro producto
- frustracion: Era el paquete pequeño
- impacto_administrativo: Revisar códigos
- impacto_economico: Riesgo de entrega de referencia errada
- workaround: Apodos del empaque
- funcion: Ficha y códigos de producto
- beneficio: Identificar la presentación

Hipótesis; impacto no medido.

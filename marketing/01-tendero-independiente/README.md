# P01 · Tendero independiente

María, personaje hipotético; personaje hipotético, no testimonio.

Atiende mostrador, recibe mercancía y recuerda cobros mientras vende. Hipótesis de trabajo: necesita resolver una operación sin reconstruir el día en varios cuadernos.

**Cargo:** Propietaria operadora de tienda de barrio. **Sector:** Comercio minorista de un único negocio.

Preparar y corregir pedidos por voz o chat, revisar referencias y pago y confirmar con control del dueño.

## Dolores propuestos para validar

### P01-D01 · Fiados sin cliente claro

- causa: Se anota un apodo sin documento del pedido
- consecuencia: El cobro pierde trazabilidad
- frustracion: No sé a quién le apunté esto
- impacto_administrativo: Reconstruir cartera
- impacto_economico: Riesgo de cobro omitido
- workaround: Cuaderno de fiados
- funcion: Crédito con cliente registrado
- beneficio: Vincular el saldo al cliente

Hipótesis; impacto no medido.

### P01-D02 · Producto oído de forma ambigua

- causa: Referencias con nombres parecidos

- impacto_economico: Riesgo de devolución por referencia

- beneficio: Revisar la referencia antes de confirmar

Hipótesis; impacto no medido.

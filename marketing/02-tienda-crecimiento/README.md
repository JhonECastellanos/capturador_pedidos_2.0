# P02 · Tienda en crecimiento

Andrés, personaje hipotético; personaje hipotético, no testimonio.

El dueño ya comparte la atención con un vendedor y necesita distinguir permisos, pedidos abiertos y cierres dentro de una sola empresa.

**Cargo:** Dueño de tienda que comienza a delegar. **Sector:** Comercio minorista con más operaciones en el mismo establecimiento.

Delegar pedidos y cobros con permisos, usando voz o chat para preparar y corregir las operaciones autorizadas.

## Dolores propuestos para validar

### P02-D01 · Todos usan el acceso del dueño

- causa: No se separan responsabilidades
- consecuencia: Se pierde atribución de cambios
- frustracion: No sé quién hizo el movimiento
- impacto_administrativo: Revisar usuarios y operaciones
- impacto_economico: Riesgo de movimiento no autorizado
- workaround: Compartir una contraseña
- funcion: Usuarios y permisos por rol
- beneficio: Delimitar acciones autorizadas

Hipótesis; impacto no medido.

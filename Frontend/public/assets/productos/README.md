# Imágenes de productos

Coloca aquí imágenes de productos, por ejemplo `p1.jpg` o `p1.png`.

Para usar una imagen estática, asigna la ruta `/assets/productos/p1.jpg` al campo `imagenUrl` del producto. Mientras no exista una imagen, la interfaz muestra una miniatura con el estado **Sin foto**; al pulsarla abre la vista ampliada.

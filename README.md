# Capturador de pedidos

Aplicación web para registrar clientes, productos, pedidos, pagos, inventario y movimientos de caja. Los datos se mantienen solo durante la sesión del navegador.

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Desarrollo local

```bash
cd Frontend
npm install
npm run dev
```

Abre la dirección que muestra Vite en la terminal.
